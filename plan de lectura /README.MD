# Future Engeneers

Analizare un proyecto para el plan de lectura del alumnado de 3º ESO de el mismo centro educativo que el mio el proyecto de este grupo trata de un robot cual tiene un sensor de ultrasonido, motor, placa arduino, el escudo, un portabaterias con sus y pilas y su respectiv cableado para que hagan sus "X" funciones. También tienen impresiones 3D como la chasis del robot con (PLA) y otra cosas como las 4 ruedas 3 soportes de ultrasonido eje direcional y  2 soportes dirección. Los problemas que este grupo a encontrado roturasde piezas 3D por forzar conectores como tornillos el montaje especificamente del eje direcional y servomotor y el montaje de las ruedas y ajugeros desplazado de lugar por error común o visual o fallar en el diseño de tinkercad en medidas o espectativas en la hora de impresión.
